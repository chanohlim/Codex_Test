# 딴 짓 리더보드

팀장님이 보면 살짝 한숨 나올 만한, 하지만 팀원들은 유쾌하게 즐길 수 있는 **React 기반 딴 짓 기록 리더보드** 웹사이트입니다. 이름, 딴 짓 종류, 시간을 입력하면 즉시 순위표와 요약 통계가 갱신됩니다.

## 주요 기능

### 1. React 상태 기반 딴 짓 기록 등록

- 사용자는 다음 정보를 입력할 수 있습니다.
  - **이름**: 리더보드에 표시될 참가자 이름
  - **딴 짓 종류**: 예: 고양이 영상 보기, 점심 메뉴 검색, 키보드 후기 읽기
  - **시간(분)**: 딴 짓에 사용한 시간
- 입력 폼은 React controlled component로 관리됩니다.
- `리더보드에 올리기` 버튼을 누르면 새 기록이 상태에 추가되고 화면이 즉시 다시 렌더링됩니다.
- 이름과 딴 짓 종류는 빈 값으로 등록되지 않으며, 시간은 1분 이상만 입력할 수 있습니다.

### 2. 자동 정렬 리더보드

- 등록된 기록은 **딴 짓 시간이 긴 순서**로 자동 정렬됩니다.
- 정렬된 목록은 `useMemo`로 계산해 불필요한 재계산을 줄입니다.
- 각 기록은 다음 정보로 구성됩니다.
  - 순위 번호
  - 참가자 이름
  - 딴 짓 종류
  - 보기 쉬운 시간 표기
- 60분 이상은 `1시간 20분`처럼 시간 단위로 변환되어 표시됩니다.

### 3. 실시간 요약 카드

상단 카드에서 현재 리더보드 상태를 요약해 보여줍니다.

- **누적 딴 짓 시간**: 모든 기록의 시간을 합산합니다.
- **참가 기록 수**: 등록된 전체 기록 개수를 표시합니다.
- **인기 딴 짓**: 누적 시간이 가장 긴 딴 짓 종류를 표시합니다.

### 4. 샘플 데이터 초기화

- `샘플로 초기화` 버튼을 누르면 기본 샘플 기록으로 리더보드가 복원됩니다.
- 서비스를 처음 열었을 때도 샘플 데이터가 표시되어 화면 구성을 바로 확인할 수 있습니다.
- 각 샘플 기록은 React list key 충돌을 피하기 위해 새 id를 부여받습니다.

### 5. 세련된 화이트 & 연한 하늘색 디자인

- 전체 톤은 화이트와 연한 스카이블루를 중심으로 구성했습니다.
- 글래스모피즘 카드, 부드러운 그림자, 둥근 버튼을 사용해 가볍고 현대적인 분위기를 냅니다.
- 모바일 화면에서도 입력 폼과 리더보드가 자연스럽게 세로 배치되도록 반응형 스타일을 적용했습니다.

## 파일 구조

```text
.
├── index.html        # Vite 앱 진입 HTML
├── package.json      # React/Vite 의존성과 실행 스크립트
├── src
│   ├── main.jsx      # React 앱, 상태 관리, 리더보드 렌더링 로직
│   └── styles.css    # 화이트/스카이블루 UI 스타일과 반응형 레이아웃
└── README.md         # 서비스 설명 문서
```

## 실행 방법

의존성을 설치한 뒤 Vite 개발 서버로 실행합니다.

```bash
npm install
npm run dev
```

브라우저에서 터미널에 표시되는 로컬 주소로 접속합니다. 기본 Vite 주소는 보통 `http://localhost:5173`입니다.

## 빌드 방법

배포용 정적 파일을 만들려면 다음 명령을 실행합니다.

```bash
npm run build
```

빌드 결과물은 `dist` 디렉터리에 생성됩니다.

## 사용 예시

1. 이름에 `김코딩`을 입력합니다.
2. 딴 짓 종류에 `고양이 영상 보기`를 입력합니다.
3. 시간에 `42`를 입력합니다.
4. `리더보드에 올리기`를 누르면 React 상태가 업데이트되고 순위표에 즉시 반영됩니다.
